# toio を PC の十字キーで動かす

toio コアキューブに PC から直接 Bluetooth LE でつないで、キーボードの矢印キーで走らせるプログラム一式です。
**toio の専用アプリもマットも不要**、キューブ単体で動きます。

---

## 1. 用意するもの

| 必要なもの | 補足 |
|---|---|
| toio コアキューブ | 単体で OK（マットがあれば座標も取れます） |
| Bluetooth LE 対応の PC | Windows 10 以降ならほぼ内蔵。無ければ USB の BLE アダプタ（数百円〜） |
| Chrome か Edge | Web 版を使う場合。Firefox / Safari は Web Bluetooth 非対応 |

> **重要**: toio は Windows の「Bluetooth とデバイス」でペアリングする必要は **ありません**。
> むしろペアリング済みだと接続を取り合って失敗することがあるので、
> 一度ペアリングしてしまった場合は Windows の設定から「デバイスの削除」をしてください。

## 3. いちばん簡単な使い方（Web 版・推奨）

1. **`toio-keyboard.bat` をダブルクリック**
   ローカルサーバーが立ち上がり、既定のブラウザでページが開きます。
   （Chrome か Edge で開いてください。別のブラウザが開いた場合は、表示された
   `http://localhost:8000/toio-keyboard.html` を Chrome にコピペ）

2. **キューブの電源を入れる**
   キューブを持ち上げて少し振る、または充電器から外すと起動します。

3. **「キューブに接続」ボタンを押す**
   Chrome のデバイス選択ダイアログに `toio Core Cube-XXX` が出るので選んで「ペア設定」。

4. **ページの中をクリックしてから矢印キー**
   これでキューブが走ります。

### 操作

| キー | 動作 |
|---|---|
| `↑` / `↓` | 前進 / 後退 |
| `←` / `→` | その場で左右に旋回 |
| `↑` + `←` など同時押し | 曲がりながら前進（内側の車輪を落とす差動制御） |
| `Shift` 押しながら | ブースト（最高速 115） |
| `Space` | 停止 |
| `1` `2` `3` | 効果音を鳴らす |
| `W` `A` `S` `D` | 矢印キーと同じ |

画面上の十字パッドはマウスでも押せます。速度・旋回の強さ・LED の色はスライダーで変更できます。

### 黒いウィンドウの表示

`.bat` を実行すると、黒いウィンドウにこう出ます（英語表示です）。

```
  toio keyboard driver - server running
  http://localhost:8000/toio-keyboard.html

  Open that address in Chrome or Edge.
  Keep this window open while you drive the cube.
  Press Ctrl + C to stop.
```

このウィンドウはサーバーなので、**操縦が終わるまで閉じないでください**（最小化はOK）。
別のブラウザが開いてしまった場合は、表示されている URL を Chrome に貼り付けてください。

### なぜ `.bat` が要るのか

Web Bluetooth は **セキュアなページからしか使えない** ルールがあり、
`file:///C:/...` で HTML を直接開いても動きません。
`.bat` が `localhost` のミニ HTTP サーバー（PowerShell 製・インストール不要）を立てることでこれを回避しています。

> **`.bat` と `.ps1` の中身が英語なのは意図的です。**
> Windows PowerShell 5.1 は `.ps1` を Shift-JIS として読むため、
> UTF-8 で保存した日本語のコメントや文字列があると構文エラーになります。
> この2ファイルは半角英数字だけで書いてあります（編集するときもご注意ください）。

Python が入っているなら、これでも同じことができます。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000/toio-keyboard.html` を開きます。

## 5. 仕組み（toio の BLE プロトコル）

toio コアキューブは BLE の GATT サーバーで、**サービスが 1 つだけ**あり、
その下に用途ごとのキャラクタリスティック（＝機能の窓口）がぶら下がっています。

```
サービス  10B20100-5B3B-4571-9508-CF3EFCD7BBAE
├─ 10B20101-…  読み取りセンサー（位置ID / Standard ID）   Notify
├─ 10B20102-…  モーター                                  Write
├─ 10B20103-…  ランプ                                    Write
├─ 10B20104-…  サウンド                                  Write
├─ 10B20106-…  モーションセンサー（傾き・衝突・姿勢）      Notify
├─ 10B20107-…  ボタン                                    Notify
└─ 10B20108-…  バッテリー                                Notify
```

やることは単純で、**モーターのキャラクタリスティックに数バイト書き込むだけ**です。

### モーター制御（時間指定つき・制御識別値 `0x02`）

| バイト | 内容 |
|---|---|
| 0 | `0x02`（時間指定つきモーター制御） |
| 1 | `0x01` 左モーターの ID |
| 2 | 回転方向 `0x01` = 前 / `0x02` = 後 |
| 3 | 速度 `0`〜`115` |
| 4 | `0x02` 右モーターの ID |
| 5 | 回転方向 |
| 6 | 速度 |
| 7 | 実行時間（10ms 単位、`0` = 無制限） |

例：両輪を速度 60 で前進、0.3 秒間

```
02 01 01 3C 02 01 3C 1E
```

**なぜ時間指定つきを使うか** — 時間無制限（`0x01` の方）で送ると、
プログラムが落ちたりキーを離したイベントを取りこぼしたとき、キューブが走り続けてしまいます。
そこで「有効時間 0.3 秒の指令を 0.08 秒ごとに送り続ける」という作りにしています。
押している間はなめらかに動き、送信が途切れれば 0.3 秒以内に自動で止まる、という安全装置です。

### 十字キー → 左右の車輪速度

左右独立の 2 輪なので、回転は左右差で作ります。

```
前後成分 f = (↑ ? 1 : 0) - (↓ ? 1 : 0)
旋回成分 t = (→ ? 1 : 0) - (← ? 1 : 0)

f == 0 のとき   左 =  t × 速度 ,  右 = -t × 速度     ← その場旋回
それ以外        左 = f×速度 + t×速度×gain×f
                右 = f×速度 - t×速度×gain×f         ← 曲がりながら前後進
```

最後に `±115` に収まるよう正規化しています。
なお速度 `1`〜`7` はモーターが回らない不感帯なので、そこは `0` に丸めています。

### そのほかのコマンド

```
ランプ点灯   [0x03, 点灯時間(10ms), 個数=0x01, ランプID=0x01, R, G, B]
ランプ消灯   [0x01]
効果音       [0x02, 効果音ID(0〜10), 音量(0〜255)]
モーター停止 [0x01, 0x01, 0x01, 0x00, 0x02, 0x01, 0x00]
```

### 受け取る通知

| 種類 | 中身 |
|---|---|
| バッテリー | 1 バイト：残量 % |
| ボタン | `[0x01, 0x80]` = 押された / `[0x01, 0x00]` = 離された |
| 位置ID | `0x01` のとき：x(2), y(2), 角度(2)… ← toio マットの上にいるとき |
| モーションセンサー | 水平検出・衝突検出・姿勢（どの面が上か） |

Web 版では、これらが右上の「キューブの状態」パネルにリアルタイム表示されます。

## 6. 暴走・事故を防ぐための作り

- 指令に有効時間を入れて連続送信（上記のとおり）
- ブラウザのタブからフォーカスが外れたら全キーをクリアして停止
- キューブ本体のボタンを押すと即停止
- ページを閉じるときに停止コマンドを送信

## 7. うまくいかないとき

| 症状 | 対処 |
|---|---|
| ダイアログにキューブが出てこない | キューブが起きているか確認（持ち上げて振る）。他のアプリ（toio Do、Scratch、前に開いたタブ）が先に掴んでいないか確認 |
| 「キューブに接続」が押せない | Chrome / Edge で `localhost` から開けているか確認。`file://` では動きません |
| 接続してもすぐ切れる | Windows の Bluetooth 設定で toio が **ペアリング済み**なら削除する。PC から離れすぎていないか確認 |
| 動きがカクつく | 他の BLE 機器や Wi-Fi の混雑が原因のことが多い。速度を下げる、PC に近づける |
| キーを離しても止まらない | 有効時間内（0.3 秒）で止まります。すぐ止めたいときは `Space` かキューブ本体のボタン |
| Python 版で `bleak` がデバイスを見つけない | Windows の Bluetooth を一度オフ／オンする。管理者権限は不要 |

## 8. 次にやると面白いこと

- **プレイマット対応** — 位置IDが取れるので、「マットの端に来たら自動で止まる／跳ね返る」が書けます（`onPositionId` に処理を足すだけ）
- **目標指定移動** — モーターには「指定座標へ移動」コマンド（制御識別値 `0x03`）もあります。クリックした場所へ走らせられます
- **2 台同時操縦** — `requestDevice` を 2 回呼んで、片方を `WASD`、もう片方を矢印キーに割り当て
- **ゲームパッド対応** — ブラウザの Gamepad API を使えば、同じ `computeWheels()` にアナログスティックの値を流し込むだけ
